# Marketing and platform walkthrough

Use this guided review to follow an agent's work, inspect the content behind it, and trace an agency campaign through SitecoreAI. Allow about 30 minutes plus publication/indexing waits; the optional metadata and new-page exercises need additional time. The audience is the team that will own content, audiences, Search, brand governance and platform operations.

For the implementation team, add the separate [local developer workshop](developer-quickstart.md). It walks through machine setup and a React heading change with immediate browser feedback, while preserving native Search. Local saved work is isolated and portal tracking is disabled. This code-edit exercise complements the editorial publishing walkthrough below; it does not publish CMS content or deploy an application change.

For individual sessions, use the [nine-loop presenter runbook](demo-loops.md). It provides accounts, preparation, numbered click paths, expected results, implementation boundaries and reset guidance for each loop, with separate marketing and IT agendas. The added [Resources A/B test](ab-testing.md) has its own setup and acceptance status; it is not covered by the earlier seven-loop rehearsal.

Repeat with **Save metadata**, then **Refresh** to verify persistence. Restore the original type with another Save and Refresh before approval/publication. The panel’s five controls are single-select, Approved versions are read-only, and Discard does not undo a completed save. See the [metadata walkthrough](resource-metadata-authoring.md#use-the-resource-metadata-panel) and [loop 5](demo-loops.md#loop-5-marketing-owns-the-content).

Edit **Summary** on that version without changing regulatory meaning, then click outside the field. Content mode autosaves on blur; wait for the **Saved** checkmark. There is no Save button in this mode. Preview it in **Editor** using the configured **Default** editing host; do not change the host for this exercise. From **Draft**, use **Actions → Approve**, then **Submit** in the workflow dialog, and confirm **Approved**. Choose **Publish Page**. Keep **Page** and **Current language (English)** selected and **Subpages** off. Uncheck **Include related items first**, then **All references**; All references hides the related-items checkbox when switched off. Select **Start publish**, then verify the new summary in the live article and resource listing.

Next, open **Content → Search Sources** and choose **Reindex Content** for **Liberty Mutual Agent Resources** (source `b5e24aff-8b5b-4653-bf66-deef52c1241a`). Published content changes require this explicit source refresh; there is no verified automatic publication-to-Search cadence. A Git deployment is not needed. To restore rehearsal wording, create another named **new English draft version**, restore the original **Summary**, click outside the field and wait for **Saved**. Complete the same approval and publication sequence, clearing Include related items before All references. Reindex the same source again, and verify the restored article, listing and Search summary. See [Sitecore's content-source workflow](https://doc.sitecore.com/sai/en/users/sitecoreai/design-components/search-experiences/manage-content-sources.html) and [loop 5's exact sequence](demo-loops.md#loop-5-marketing-owns-the-content).
