## Native setup and evidence

1. Open the customer's tenant in Agentic Studio and create or duplicate a supported drafting workflow. Name it `Liberty Mutual — Cedar Ridge agency growth`.
2. Select the published Liberty Mutual Agent Portal Brand Kit. Use the full prompt as input. If a workflow builder is available, use four stages: account brief, role copy, source/brand review, review package. Tool availability must be verified in the native UI; these are intended stages, not claims about installed capabilities.
3. Run with the supplied fictional account context. Stop at a draft review package. No email sending, audience activation, automated approval or public publishing belongs in this workflow.
4. Save the native workflow ID, run ID, timestamp, selected Brand Kit ID, output artifact IDs/links and final run status in the implementation evidence log. Record any failed or partial stages.
5. A marketer reviews the actual native output against the checklist and the reference draft. Only approved changes should be moved into the existing CMS datasources and approved through the installed Sitecore workflow.

## Acceptance checks

- The native run identifies the selected Brand Kit, input campaign and account.
- All four role variants exist, differ in purpose, and retain a neutral fallback.
- Every CTA is in the supplied route allowlist and opens the corresponding authored CMS page.
- Every factual product or legal assertion has an exact primary source; recommendations and fictional account facts are labeled in the internal source ledger.
- No financial figure, account score, private identity, credential or client record appears in visitor-facing copy.
- Texas workers compensation guidance does not become a blanket statement that coverage is universally optional or universally required.
- The account-manager variant recommends discovery/referral, not actions beyond that colleague's authorization.
- Draft outputs remain reviewable; no live send or publication occurred.
- Workflow evidence records actual native results. The checked-in reference draft is never used as proof of Agentic execution.

## Demonstration narrative for marketing and IT

Marketing sees one agency-level opportunity translated into useful role-specific content, with Brand Kit and source review before approval. IT sees limited inputs, stable identifiers, structured outputs, explicit API boundaries and separate editorial publishing. UDL audience matching and server-side authorization remain outside the drafting workflow. The platform personalization rule selects an approved content variant after login; it never grants access to agency records.

The measurement plan is a proposed evaluation design. A sandbox cannot establish commercial conversion lift from manufactured activity. For a later real study, randomize and analyze at agency level to reduce cross-colleague contamination and agree event semantics, consent and retention with the customer.
